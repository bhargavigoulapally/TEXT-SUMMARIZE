# 📝 AI Text Summarization App

An AI-powered **Text Summarization Web App** built with Python and Streamlit. The application takes a long piece of text from the user and generates a shorter summary containing the most important information.

## 🚀 Live Demo

👉 **Try the application:**
[Text Summarization App](https://text-summarize-kbn7wdvmvwfbvc3w9bsvmm.streamlit.app/?utm_source=chatgpt.com)

## 📌 Project Overview

Reading long articles, documents, and paragraphs can take a lot of time. This project provides a simple solution by automatically summarizing text into a concise and easy-to-understand format.

The user enters text into the application, clicks the **Summarize** button, and receives a summarized version of the input.

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd text-summarize
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```

The application will open in your browser at:

```text
http://localhost:8501
```
